# Provider logos

These SVGs identify the providers in Paseo's Usage view and in the promotional previews. They are bundled with the plugin; displaying a logo does not require a network request.

- `antigravity.svg` is the unmodified Antigravity logo from the [official ACP registry](https://github.com/agentclientprotocol/registry/blob/7f1a88d4ccca205eaa611ca9d38e0b2b13890450/antigravity-acp/icon.svg), pinned to commit `7f1a88d4ccca205eaa611ca9d38e0b2b13890450`. The registry's Apache 2.0 license is included in `ACP-LICENSE.txt`.
- `kiro.svg` is the unmodified icon from [Kiro's official website](https://kiro.dev/icon.svg), retrieved on October 12, 2026. Kiro is listed among [ACP-compatible agents](https://agentclientprotocol.com/get-started/agents), but its icon was not available in the ACP registry at retrieval time.

Provider names and logos belong to their respective owners. The project's MIT license does not relicense these third-party marks.
